## Behaviour and validation

- Waiting tables remain server-backed when a player goes home, including clients still using the old leave endpoint. Explicit abandonment is a separate API action. Waiting tables appear before active matches.
- Invitations reuse the selected waiting table, and concurrent invite requests share one table creation operation. Authenticated rejoin restores the existing seat instead of allocating a duplicate.
- Host removal is restricted to private lobbies and private games originally containing three or four players. Self-removal and non-host removal are rejected. Stable public seat IDs prevent stale confirmations from removing a different person after a lobby reorder.
- During play, removed seats retain their internal indexes and archived result while losing session access. Their card disappears from the active score strip. Rematches prune removed seats.
- Score-strip order is descending score with seat-index tie-break; turn, chat and profile actions continue to use the original seat index.
- Point-scaled flames now emit around all four tile edges. Emitters and effect particle counts are bounded.
- 98 automated checks, including server restarts, session revocation, stale seat confirmation and rematches. Responsive checks at 360 px and 320 px.
