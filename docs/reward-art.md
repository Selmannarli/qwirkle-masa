# Reward art

Tool: built-in imagegen, transparent-background generation. Game tile paths remain the existing shared vectors.

Final project asset: `public/assets/reward-trophy-v1.webp` (176,384 bytes, alpha retained). The generated PNG was format-compressed into WebP for the menu. Its dimensions and illustrated content were retained.

Final prompt:

> Use case: stylized-concept. Project asset: transparent cutout reward trophy for a polished purple mobile tile board game home screen. Create ONE gorgeous chunky golden trophy, rounded cup with wide curved handles, big embossed five-point golden star on its front, short shiny gold stem, small beveled deep-purple pedestal. Three-quarter front view, subtly tilted clockwise, playful premium 3D casual-game rendering, warm yellow gold with amber shading, broad soft specular highlights, slight lavender reflected light. Entire isolated object centered, generous transparent margins, no cropping. Actual transparent alpha background. No text, no letters, no numbers, no coins, no surrounding tiles, no extra objects, no background or cast ground shadow. It must read clearly when displayed 145 pixels tall on a dark purple UI.
